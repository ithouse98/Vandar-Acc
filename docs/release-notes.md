# وَندار ۱.۰

- مدیریت مشتریان، خدمات، فاکتور فروش، دریافت‌ها و گزارش‌های مالی فارسی.
- هشت قالب فاکتور، از جمله قالب رسمی A4 افقی؛ دانلود مستقیم PDF با نام مشتری، تاریخ و شماره سند.
- اعتبارسنجی موبایل، نمایش اختیاری گذرواژه، مبلغ سه‌رقمی با پیش‌نمایش فارسی و ارقام فارسی در توضیحات.
- بارگذاری لوگو و مهر و امضای شفاف فروشنده.
- اجرای پرتابل کنار ساعت ویندوز و نصب اختیاری سرویس با میانبر تمام‌صفحه.

بستهٔ Release بدون پایگاه داده یا کلید شخصی ساخته شده است. راهنمای نصب و بازیابی در فایل «راهنما.txt» داخل ZIP قرار دارد.
