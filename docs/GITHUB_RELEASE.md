# انتشار وَندار در GitHub

برای انتشار به Git، Node.js 24.21.0، .NET Framework 4.5 یا جدیدتر و [GitHub CLI](https://cli.github.com/) روی رایانهٔ سازنده نیاز دارید. ورود GitHub CLI یا اعتبار ذخیره‌شدهٔ Git برای GitHub لازم است.

۱. تغییرات کد را بررسی و commit کنید. اسکریپت فقط درخت Git تمیز را منتشر می‌کند و فایل‌های `data/`، `dist/` و کلیدها را نباید به Git اضافه کنید.

۲. برای انتشار این نسخه در مخزن `ithouse98/Vandar-Acc`، فایل [Upload-To-GitHub.cmd](../Upload-To-GitHub.cmd) را اجرا کنید. این فایل کد را روی شاخهٔ `main` می‌فرستد، Setup و ZIP موجود را بررسی و آپلود می‌کند و پس از وجود هر دو فایل، Release را منتشر می‌کند. اگر انتقال قطع شود، دوباره همان فایل را اجرا کنید تا پیش‌نویس نیمه‌کاره ادامه یابد.

برای فقط ساخت و آزمون بسته‌ها، بدون ارسال به GitHub:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish-release.ps1 -BuildOnly
```

۳. برای مخزن یا نسخهٔ دیگر، پارامترها را مشخص کنید:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish-release.ps1 -Repo OWNER/REPO -Version v1.2.1
```

اگر مخزن هنوز وجود نداشته باشد، اسکریپت آن را **خصوصی** می‌سازد. برای ایجاد مخزن عمومی، `-Visibility public` را اضافه کنید. مخزن پیش‌فرض `ithouse98/Vandar-Acc` از قبل عمومی است. اگر `origin` از قبل تنظیم شده باشد، اسکریپت فقط وقتی ادامه می‌دهد که به همان مخزن اشاره کند. متن توضیحات Release در `docs/release-notes.md` است؛ برای نسخه‌های بعدی آن را ویرایش کنید.

**مهم:** فایل ZIP شخصیِ ساخته‌شده بدون `--release` شامل پایگاه داده و کلید رمزگذاری است و نباید در GitHub آپلود شود. اسکریپت انتشار بسته‌ای تازه با پوشهٔ دادهٔ خالی می‌سازد و پیش از آپلود محتویات ZIP را بررسی می‌کند.

Release هر دو فایل `Vandar-Portable-v1.2.1-win-x64.zip` و `Vandar-Setup-v1.2.1-win-x64.exe` را دریافت می‌کند. Setup نیز فقط همان بستهٔ پاک را در خود دارد. اسکریپت انتشار از خروجی‌های موجود در `dist` استفاده می‌کند و اگر هیچ‌کدام وجود نداشته باشند، آن‌ها را می‌سازد. اگر فقط یکی از دو فایل موجود باشد، برای جلوگیری از انتشار ناقص متوقف می‌شود.

بستهٔ جدید شامل لانچر کنار ساعت، سرویس ویندوز، اسکریپت نصب و حذف سرویس، میانبر تمام‌صفحه و ابزار بازیابی گذرواژه است. Setup سرویس را نصب و اجرا می‌کند و کد راه‌اندازی نخستین اجرا را نشان می‌دهد. نصب سرویس دسترسی Administrator می‌خواهد و داده را در `%ProgramData%\Vandar\data` نگه می‌دارد. راهنمای داخل ZIP جزئیات را توضیح می‌دهد.
